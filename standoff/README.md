# 3D Shooter - Standoff

## Обновления: 3D Руки и Враги

### Что было добавлено:

#### 1. 3D Руки Игрока
- Процедурно сгенерированные руки из геометрий Three.js
- Детализированные пальцы (proximal и distal фаланги)
- Правая и левая руки с предплечьями
- Кисти прикреплены к камере для эффекта от первого лица
- Цвет кожи: #ffccaa с реалистичными материалами

#### 2. Анимации Рук
- **Отдача при стрельбе**: Руки отступают назад и вращаются вверх при выстреле
- **Ходьба**: Свинг (bobbing) рук при движении персонажа
- **Приседание**: Уменьшенная амплитуда движения при приседании
- **Базовая позиция**: Руки возвращаются в исходное состояние при остановке

#### 3. Улучшенные Враги
- Замена простых кубов на 3D модель террориста (cs2_terrorist.glb)
- Автоматическое масштабирование и центрирование модели
- Фолбэк на кубические враги, если модель не загрузится
- Улучшенный хитбокс для более точного определения попаданий

#### 4. Анимации Врагов
- Базовая анимация ходьбы (если модель поддерживает)
- Реалистичная позиция глаз для проверки видимости
- Правильная высота оружия для стрельбы

### Технические детали:

#### Структура кода:
- `loadHands()`: Создает и добавляет 3D руки в сцену
- `loadEnemyModel()`: Загружает модель террориста
- `updateEnemies()`: Обновляет позицию и анимацию врагов
- `animate()`: Управляет анимациями рук в каждом кадре
- `shoot()`: Добавляет эффект отдачи рукам

#### Файлы:
- `standoff/index.html`: Основной файл игры с обновлениями
- `standoff/src/source/cs2_terrorist.glb`: 3D модель врага
- `standoff/src/source/specnaz.glb`: Модель спецназа (для будущего использования)

### Как запустить:
```bash
cd standoff
python3 -m http.server 8080
```
Откройте http://localhost:8080 в браузере

### Управление:
- **WASD**: Движение
- **Мышь**: Прицеливание
- **ЛКМ**: Стрельба
- **Пробел**: Прыжок
- **Shift**: Приседание
- **Мобильный**: Виртуальный джойстик и кнопки

### Особенности реализации:
- Руки не блокируют обзор (позиционированы сбоку и снизу)
- Сохранена производительность (оптимизированные геометрии)
- Совместимость с существующей системой коллизий
- Плавные анимации без использования внешних библиотек
